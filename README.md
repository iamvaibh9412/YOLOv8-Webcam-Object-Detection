# YOLOv8-Webcam-Object-Detection

Real-time object detection using YOLOv8 and OpenCV

🔹 Project Overview

This project demonstrates real-time object detection using YOLOv8 via your computer’s webcam. The system detects objects, draws bounding boxes around them, and displays the object name and confidence live.

It is dynamic and can detect any object in the YOLOv8 COCO classes, including:

Person

Cell phone

Mouse

Cup

Bottle

Watch
…and many more.

This project is built to be fast, reliable, and easy to run locally in VS Code or any Python environment.

🔹 Features

Real-time object detection with webcam feed

Dynamic detection for any COCO object class

Bounding boxes and labels displayed live on the video

Confidence threshold to filter low-confidence detections

Prints detected objects to console for monitoring

Easy to run in VS Code or any local Python setup
